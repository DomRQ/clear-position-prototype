# Clear Position Design Authority
# Purpose

This repository contains the approved Clear Position interactive visual prototype. It is the design authority for bringing the current Clear Position website closer to the approved launch appearance.

# Design priority

The images in the assets folder define the intended visual language, including layout, spacing, typography, navigation, cards, buttons, panels, forms, colours, responsive behaviour and system states.

The existing HTML, CSS and JavaScript demonstrate the intended relationships between the screens. They are a prototype, not production application code.

# Required approach

Use the prototype as the visual authority while respecting the current Clear Position website structure and existing functionality.

Create reusable web components and responsive desktop and mobile layouts.

Preserve the calm, professional, evidence-led Clear Position appearance.

Do not redesign the brand.

Do not invent new products, prices, customer journeys, claims, legal conclusions or functionality.

Do not remove existing working functionality merely because it is not represented in the prototype.

The website remains hosted on Cloudflare. Google Stitch is being used only to assist with design alignment and front-end development.

All generated designs and code must be reviewed before being introduced into the production repository.

# Screen references

The assets folder includes public pages, pathway screens, route results, membership screens, signed-in areas, matter management, resource access, credit functions, professional handoff, mobile layouts and system-state references.

These screens should be treated as parts of one consistent design system rather than unrelated page designs.

# Immediate objective

Produce a coherent launch-ready web design system and suggested front-end components that bring the current Clear Position website materially closer to this approved prototype.
