CLEAR POSITION — INTERACTIVE DEMONSTRATOR v1
=============================================

PURPOSE
-------
This is a high-fidelity clickable aesthetic demonstrator assembled from the approved Clear Position PNG design authorities.

It is not yet the live platform. It does not process:
- accounts or passwords;
- personal information;
- payments or credits;
- uploaded documents;
- live recommendations;
- professional invitations.

HOW TO INSTALL
--------------
1. Extract this ZIP.
2. Open the extracted folder.
3. Copy ALL contents inside it into:
   Clear-Position-website\interactive-demonstrator-v1
4. Double-click index.html.
5. Chrome or Microsoft Edge should open the demonstrator.

IMPORTANT
---------
Do not copy any .env file into this demonstrator.
Do not overwrite the existing website root or the earlier ux-prototype folder.

HOW TO USE
----------
- Click the numbered gold interaction areas.
- Open “Screen map” to jump directly to any screen.
- Use Previous / Next or the left and right arrow keys.
- Use the checkboxes to hide hotspots or display the approved screen at its natural size.
- Mobile and System States are reference-board destinations.
